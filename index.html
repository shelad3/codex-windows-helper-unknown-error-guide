Windows troubleshooting guide

Fixing “setup refresh had errors” in Codex Desktop

A concise, evidence-based guide to separating command-runner failures from problems in PowerShell, Git, or your project.

Key idea: the message is generic. It usually means Codex failed while preparing its Windows sandbox or bundled runtime before your command could run.

What the investigation showed

Before executionThe failure can occur before PowerShell, CMD, Git, or the repository is reached.
Not always globalA fresh workspace or alternate path may work while one existing path fails.
Multiple causesOwnership, ACLs, file locks, stale path state, and sandbox mode can produce the same top-level message.

Recommended recovery order

1. Close elevated tools

Close Codex and editors launched as Administrator. End leftover ChatGPT.exe processes in Task Manager, reopen Codex normally, and retry.

2. Inspect the exact failing path

Look for the nested sandbox error. If it identifies .git or .codex, check ownership before changing permissions:

(Get-Acl ".").Owner
(Get-Acl ".git").Owner
(Get-Acl ".codex").Owner

3. Try the temporary sandbox workaround

Back up %USERPROFILE%\.codex\config.toml, then test:

[windows]
sandbox = "unelevated"

This changes the isolation model, so treat it as a workaround and restore the previous setting if it does not help.

4. Test a new path

If only one workspace fails, test an empty workspace or a reversible Windows junction alias. Keep the real repository, history, and branch unchanged.

What not to do first

Do not delete the global Codex cache blindly.
Do not reset every repository ACL.
Do not disable Windows security tools.
Do not assume Git or PowerShell is broken.

Likely causes

Possible causeUseful clue
Sandbox ACL failureSetNamedSecurityInfoW failed: 5 or access denied.
Locked runtime fileOS error indicating a file is being used by another process.
Stale path-specific stateThe same physical files work through a new path.
Elevated/unelevated mismatchElevated execution works while the normal runner fails.
